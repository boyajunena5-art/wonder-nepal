WANDER NEPAL - TRAVEL & TOURISM WEBSITE

PROJECT PAGES
1. index.html  - Home page
2. about.html  - About Us page
3. contact.html - Contact page

FOLDER STRUCTURE
wander_nepal/
  index.html
  about.html
  contact.html
  css/
    style.css
  js/
    script.js
  README.txt

HOW TO RUN
1. Extract the ZIP file.
2. Open the wander_nepal folder.
3. Double-click index.html, or open it with a browser.
4. Use the navigation bar to move between Home, About Us and Contact.

FEATURES
- Responsive navigation bar with Font Awesome icons.
- Three connected pages.
- CSS Grid and Flexbox layouts.
- Responsive design for mobile, tablet and desktop.
- Contact form with JavaScript validation.
- Shared external CSS and JavaScript files.

NOTES
- Internet is required for Google Fonts, Font Awesome and the remote destination photographs.
- The contact form is a front-end demonstration. It validates input but does not send or store messages.
- Replace the sample contact details on contact.html with your own if required.
